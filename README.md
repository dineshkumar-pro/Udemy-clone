# Udemy Clone 🎓

A simple **Udemy Clone website** created using **HTML and CSS**. This project is designed to recreate the basic look and layout of the Udemy learning platform while practicing frontend web development concepts.

### 🛠️ Technologies Used

* HTML5
* CSS3

### ✨ Features

* Udemy-inspired homepage design
* Course sections and course cards
* Navigation bar
* Search bar UI
* Responsive and clean layout
* Styled using CSS

### 🎯 Purpose

This project was created to improve my understanding of **HTML structure, CSS styling, layouts, positioning, and basic frontend design**.

### 📌 Note

This is a **frontend-only project** created for learning and practice. No backend or database functionality is included.
